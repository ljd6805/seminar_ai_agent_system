### 2. OpenCode Agent System & Team

OpenCode를 Agent Runtime으로 활용하고 Python Harness/Loop와 Subagent Team을 결합하는 방법을 학습하기 위한 상세 슬라이드입니다.

주요 내용:

- `opencode run` 기반 Headless Agent 실행
- Python이 State / Loop / Retry / Validation / Logging을 맡는 구조
- OpenCode와 Python Harness의 책임 분리
- Session 관리와 재현성
- Permission과 안전한 자동화
- Primary Agent + Subagent 구조
- Planner / Developer / Tester / Reviewer 역할 분리
- Python Task Board를 이용한 Team orchestration
- Agent Loop 단계별 실습
- 운영 구조로 확장할 때의 Queue / Server / Validator / Human Approval

`https://ljd6805.github.io/seminar_ai_agent_system/opencode-agent-system-team.html`
